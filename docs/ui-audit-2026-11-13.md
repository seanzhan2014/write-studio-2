# 电脑与手机 UI 检查

日期：2026-11-13。环境：Windows、Node.js 24.11.1、Chromium / WebKit。

## 本轮修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 手机大纲编辑的聊天、属性按钮没有图标 | 隐藏文字的 CSS 同时隐藏了图标的 span，留下空白按钮 | 仅隐藏文字，保留图标与无障碍名称 |
| 小屏大纲标题过窄、换行裁切 | 320px 下标题只剩约 59px；脱离原容器测量的文本镜像丢失上下文样式，屏幕旋转后也没有重新测量 | 480px 以下标题独占一行；镜像保留字体、行高、内边距与换行样式，宽度变化后重新测量；去除标题框的手动缩放柄 |
| 数据管理的导入、导出按钮上下堆叠 | 卡片摘要规则误选中 Mantine Group，将按钮组改成 grid | 摘要规则排除按钮组，恢复同行布局 |
| 手机部分设置控件过小 | 导入、导出按钮约 30px，部分按钮和表单约 36px，云端同步开关约 24px | 设置页相关按钮、输入框和分类页签至少 44px；开关保留轨道外观并扩大实际操作区 |
| 多个设置开关只有状态名称 | 读屏只能读出“已开启/已关闭”，无法区分设置用途；语言选择也缺少名称 | 开关使用明确名称与 switch / aria-checked，补齐语言选择标签，保留键盘操作和设备本地保存 |
| 平板折叠侧栏仍占 180px | 768–1023px 下全局强制宽度覆盖折叠状态，设置内容少了 124px | 折叠侧栏恢复 56px，展开时保留 180px；覆盖 768 / 820 / 1023px 及展开、折叠、返回写作状态 |
| 聊天窗口缩小时最新消息移出可视区域 | 电脑切到手机或压缩高度后，输入区仍在，但消息列表保持旧滚动位置 | 列表尺寸变化时继续跟随最新消息；用户已向上阅读历史时保留阅读位置 |

同时修正 UI 测试中的旧工作页签名称、已移走的审校规则入口、已删除的介绍文案以及过时的大纲编辑前置步骤。没有恢复功能介绍或冗余帮助文字。

## 范围与方法

- 使用独立测试数据库，未修改现有业务文章、真实模型密钥或云端数据库内容。
- 人工查看生产构建的正文、生成、数据管理、AI 任务设置及章节与大纲编辑，核对实际图标、排列、触控范围和标题显示。
- 自动回归覆盖正文与版本、章节与大纲、全文编辑、聊天、生成、插图、人物与照片、人物关系、文章资料、外观、AI 服务、AI 任务、数据管理、系统设置，以及菜单、抽屉、弹窗和错误状态。
- 桌面包括 1440×900、1280×720；平板包括 768px、820px 等宽度；手机重点覆盖 320×568、390×844、667×375 和 390×480，并包括长内容、横向溢出、触摸滚动、深色模式和模拟键盘视口。
- 新增专项检查开关的键盘操作与刷新持久化、四档手机设置布局、导入导出同行布局，以及长标题在桌面/手机/平板间切换后的完整显示。

## 已知验证边界

- 手机使用浏览器尺寸与触摸仿真；WebKit 回归不等同于真实 iPhone / iPad 的 Safari。软键盘使用压缩高度及 visualViewport 模拟，仍建议真机补查输入法候选栏、系统缩放和刘海安全区域。
- AI 服务测试使用本地模拟接口，未执行付费模型请求。
- 内嵌浏览器读取开发流式页面时出现 hydration 异常，Chrome 开发页和生产构建可正常打开；视觉检查以生产构建为准。
- 原有 implementation-contract 结构测试在修改前的 Git HEAD 副本上即有 6 项失败，涉及旧 SQL 列表、旧同步说明、编辑器调用形式、已删除说明文字、保存函数签名和命名设置来源。本轮同名失败数量未增加；实际 UI 行为另由浏览器回归验证。
- lint 原先扫描运行时生成目录，并报告一个既有的未使用导入；已排除生成目录并移除该导入。
