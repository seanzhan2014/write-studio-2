# 全面检查修复与回归记录

日期：2026-10-31。环境：Windows、Node.js 24.11.1、npm 11.6.2。

## 功能修复

| 问题 | 修复与验证 |
| --- | --- |
| F1 插图使用过期正文 | 选区来源绑定当前正文和版本；正文变化后使旧来源失效。生成结果中的片段也随正文变化重置。桌面、手机均覆盖选区入口、整篇选景、编辑保存后重新生成，并检查提交的新正文。 |
| F2 服务端生成上下文遗漏优秀片段 | 两处自动构建上下文均传入优秀片段开关及所选 ID；真实测试模型请求回归通过。 |
| F3 缺少 If-Match 时被当成 0 | 快照和增量接口先检查请求头存在且非空，再检查非负安全整数；缺失、空白及无效值返回 428，不写入数据。 |
| F4 接受悬空或跨大纲的正文版本 | 快照和增量写入均校验最终的当前、默认版本属于对应大纲；无效引用返回 422，整个写入不生效。允许在同次保存中新建并选中版本；删除引用版本时必须同时清除或切换引用。 |
| F5 清除业务数据不完整 | 显式删除照片任务、同步历史、聊天请求记录及关联图片，并清理本设备的离线正文、照片草稿和聊天重试队列。图片删除失败保留重试凭据，不恢复已清除的业务快照；云存储分页遇到缺失或循环游标会在清除前拒绝。 |

清理边界按确认结果执行：保留模型、密钥、系统配置、磁盘导出文件和恢复备份。测试覆盖配置与备份保留、图片删除失败后的重试，以及刷新后不会恢复旧业务数据。删除测试均使用独立测试库、合成文件及模拟模型服务，未清除现有业务库。

另修复模型服务弹窗的滚动归属和手机目录行被操作栏覆盖的问题，并统一模型 ID 复制按钮字号。

## 依赖与运行方式

升级到本轮验证兼容的版本：Vinext 1.4.0、React/React DOM 19.3.1、Next 16.4.3、Vite 8.3.5，并更新相关工具链和锁文件。全依赖及生产依赖安全扫描均为 0 漏洞。

默认构建继续用于 Node 自托管。Sites 构建设置 `WRITER_STUDIO_BUILD_TARGET=sites`，仅该目标加载 Cloudflare 插件，避免 Node 生产服务加载 Cloudflare 专用模块。开发与测试入口适配新版 Vite/Vinext。

## 检查体系修复

- 修复原生 Node ESM 的 TypeScript 相对导入及适配器测试加载。
- 更新旧 SQL、任务上下文、工作页签、模型选择、手机保存、菜单和大纲属性入口的断言，保留行为与持久化检查。
- 将历史目录及构建产物移出类型和 lint 检查范围，修复当前源码和测试的实际诊断；保留 React hooks 检查。
- 私有图片及远程预览使用原始图片 URL，相关文件明确说明不依赖 Next 图片优化服务；其余检查保持启用。
- 测试库按进程使用独立目录，删除前核对路径边界，开发测试缓存也隔离。
- `npm test` 增加类型检查和零警告 lint 门禁。
